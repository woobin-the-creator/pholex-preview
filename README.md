# pholex-preview

Pholex UI 시안 비교용 **상시** 정적 프리뷰. 내용은 진행 중인 작업에 따라 매번 루트째 교체된다.

- 데이터는 전부 합성 데모 픽스처다 (실제 사번·이름·부서·lot 아님).
- 백엔드 없이 도는 정적 빌드이므로 일부 API 호출은 404가 난다 — 의도된 상태다.

## 현재 올라간 것 (2026-08-06)

라인 기본 필터 · 첫 접속 라인 선택 시안 3화면 — 상단 탭으로 전환, 라이트/다크 토글 포함.

- `#a` 첫 접속 라인 선택 모달 (추천 있음 / 없음 토글)
- `#b` 라인 관리 · 부서 매핑 shuttle
- `#c` 키워드 슬롯 빈 상태 (라인 미선택 / 기본 필터 없음 토글)
